## 📌 1. Project Overview

**NutriNova AI** is an AI-powered personalized nutrition platform designed to help individuals make informed food choices and develop healthier eating habits.

The platform aims to provide a personalized nutrition experience by considering individual characteristics, dietary preferences, lifestyle choices, food allergies and intolerances.

Unlike generic diet-planning approaches, NutriNova AI focuses on personalization. Users can create their nutrition profiles, explore meal recommendations, manage food preferences and interact with an AI-powered nutrition assistant.

The project combines frontend web development, Python-based backend functionality, nutrition-related datasets and AI integration to create an interactive nutrition ecosystem.

**Project Name:** NutriNova AI  
**Domain:** Artificial Intelligence, Machine Learning & Web Development  
**Project Category:** Personalized Nutrition Technology  
**Project Type:** Web-Based Application  
**Development Status:** Under Development

---

## 🎯 2. Problem Statement

Maintaining a balanced diet can be challenging because nutritional requirements and food preferences differ from person to person.

Some common challenges include:

- Generic diet plans that do not consider individual preferences.
- Difficulty finding suitable food alternatives.
- Food allergies and intolerances that restrict food choices.
- Limited awareness of nutritional values.
- Difficulty organising daily meals.
- Lack of easily accessible personalized nutrition guidance.

Traditional diet-planning approaches may not provide the level of personalization that individuals need.

**NutriNova AI aims to address these challenges through an interactive and personalized technology-driven platform.**

---

## 💡 3. Proposed Solution

NutriNova AI provides a centralized platform where users can maintain their nutrition profiles and receive personalized food-related guidance.

The platform focuses on:

1. Collecting relevant user information.
2. Understanding dietary preferences and restrictions.
3. Personalizing the user experience.
4. Providing meal suggestions.
5. Offering nutrition-related assistance.
6. Supporting informed food choices.

The long-term goal is to develop an intelligent nutrition ecosystem that makes personalized dietary planning easier and more accessible.

## ✨ 4. Key Features

### 👤 4.1 Personalized User Profile

Users can create their nutrition profiles by providing relevant information.

Profile information includes:

- Name
- Age
- Height and weight
- Gender/sex selection
- Activity level
- Dietary preferences
- Food allergies
- Food intolerances
- Disliked foods
- Cuisine preferences

The collected information helps personalize the platform experience.

### 🥗 4.2 Personalized Diet Planning

The My Diet section focuses on meal recommendations according to user preferences.

Meal categories include:

- Breakfast
- Lunch
- Evening Snacks
- Dinner

The objective is to make meal planning more convenient and personalized.

### 🤖 4.3 AI Nutrition Assistant

NutriNova AI includes an interactive nutrition assistant designed to help users with food-related questions and general nutrition guidance.

The assistant aims to provide:

- Nutrition-related information.
- Food suggestions.
- General dietary guidance.
- Answers to food-related questions.
- Assistance with understanding food choices.

### ⚠️ 4.4 Allergy and Intolerance Management

Users can specify food allergies and intolerances in their profiles.

This information can be used to filter unsuitable recommendations.

Food allergy information must always be independently verified. The platform does not guarantee that a food is allergen-free.

### 🍱 4.5 Food Comparison

The platform aims to help users compare different food options based on available nutritional information.

Comparison parameters may include:

- Calories
- Protein
- Carbohydrates
- Fat
- Other available nutrients

### 📅 4.6 Meal Planning

The platform is designed to support structured meal planning.

Future improvements include weekly meal schedules and more advanced personalized recommendations.

## 📊 9. Dataset and Data Sources

Nutrition information is an important component of personalized diet-planning applications.

The following publicly available resources are useful references for food composition and nutrition-related information.

### 9.1 USDA FoodData Central

**Organization:** United States Department of Agriculture (USDA).

Provides food composition and nutritional information, including:

- Calories and energy.
- Protein.
- Carbohydrates.
- Total fats.
- Vitamins.
- Minerals.
- Food composition details.

**Potential application:**
Reference for nutritional values and food composition information.

**License:** CC0 1.0 Public Domain Dedication.

Official resource: `fdc.nal.usda.gov`

### 9.2 Open Food Facts

An open and collaborative food-products database.

Provides information such as:

- Product ingredients.
- Nutrition facts.
- Food labels.
- Energy values.
- Product categories.
- Allergen information where available.

**Potential application:**
Food product information, ingredient exploration and nutritional comparison.

**License:** Open Database License (ODbL) 1.0 for the database, with applicable licensing for individual contents.

Official resource: `world.openfoodfacts.org`

### 9.3 FAO/INFOODS

**Organization:** Food and Agriculture Organization of the United Nations (FAO).

Provides access to international food composition tables and databases.

**Potential application:**
Reference for food composition information across different countries and regions.

Official resource: `fao.org/food-composition`

### Data Attribution

The above resources are documented as potential reference sources for NutriNova AI.

Their inclusion in this documentation does not imply that their datasets or APIs are already integrated into the current application.

The exact origin, version and license of any dataset actually used in the project should be documented separately.

## 🚀 12. Installation and Setup

Follow these steps to run NutriNova AI locally.

### Prerequisites

- Python installed.
- Visual Studio Code.
- Git.
- A modern web browser.

### Step 1: Clone the Repository

```bash
git clone https://github.com/khush7v7i/NutriNova-AI.git
```

### Step 2: Navigate to the Project

```bash
cd NutriNova-AI
```

### Step 3: Open the Project

```bash
code .
```

### Step 4: Run the Frontend

Navigate to the frontend directory.

Open `index.html` using a browser or VS Code Live Server.

### Step 5: Install Backend Dependencies

Navigate to the backend directory:

```bash
cd frontend/backend
```

Install the required dependencies:

```bash
pip install -r requirements.txt
```

### Step 6: Configure Environment Variables

Refer to `.env.example` and the setup documentation.

Create your own local `.env` file with the required credentials.

Never upload actual API keys or private credentials to GitHub.

### Step 7: Start the Backend

Run the backend using the startup instructions documented in the project setup files.

## 🔐 13. Privacy and Security

NutriNova AI considers user privacy and application security important.

Security practices include:

- Keeping API keys private.
- Using environment variables for sensitive configuration.
- Excluding `.env` files from Git.
- Avoiding exposure of private credentials in frontend JavaScript.
- Limiting the collection of unnecessary personal information.

User profile information stored in browser Local Storage remains accessible through the user's browser and should not be treated as secure server-side storage.

NutriNova AI is an educational technology project and is not a substitute for professional medical or nutritional advice.

- AI-generated information may contain errors.
